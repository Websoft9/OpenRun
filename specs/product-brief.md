# OpenRun Product Brief

## Positioning

An open source software directory and aggregator that helps users discover, compare, and run self-hosted software.

## Users

- Developers looking for open source alternatives
- Individuals and small teams that need self-hosted software
- Operations teams evaluating software for their company

## Problem

Open source software information is scattered across GitHub, official sites, and docs. It is hard to quickly answer:

- What does this software do?
- Is it a fit for me?
- How do I run it?
- What alternatives exist?

## Value

- Unified catalog and taxonomy
- AI-generated summaries, features, and use cases
- Bilingual English and Chinese content
- Traceable sources and update timestamps

## M1 Scope

- 50 self-hosted open source products
- List, category, detail, and search pages
- AI summaries and bilingual content
- Admin review and publishing
- External submissions with an editorial review queue

## Non-goals

- User accounts and community features
- Self-service publishing without editorial review
- One-click deployment
- Full market coverage

## Success Metrics

- 50 products reviewed and published
- Core pages are searchable and browsable
- Every fact is traceable to a source
